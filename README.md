# BioBrief Agent 🧬

제약·바이오 기업 취업을 준비하는 사용자를 위한 **기업 리서치 AI
Agent**입니다.

관심 기업을 입력하면 해당 기업을 이해하는 데 도움이 되는 주요 뉴스 7건을
선별하고, 뉴스 분석과 추가 리서치를 통해 기업·산업·직무 관점의
인사이트를 제공합니다.

## 주요 기능

-   관심 기업의 주요 사업 및 최근 이슈 파악
-   취업준비생이 읽어야 할 서로 다른 주제의 뉴스 7건 선정
-   복잡한 바이오 뉴스를 이해하기 쉽게 설명
-   뉴스에서 중요한 수치와 의미 분석
-   공식 자료를 활용한 추가 리서치
-   관련 직무 및 필요 역량 연결
-   자소서·면접에 활용할 수 있는 기업 인사이트 제공
-   전체 뉴스를 종합한 기업 방향성 분석

## Input

기업명을 입력합니다.

예시:

> 삼성바이오로직스 분석해줘

## Process

기업 파악\
→ 주요 뉴스 7건 선정\
→ 뉴스 분석\
→ 추가 리서치\
→ 취업준비생 관점의 BioBrief 생성

## Output

최종 결과는 Markdown 형식의 기업 리서치 브리핑으로 생성됩니다.

예시:

`삼성바이오로직스_BioBrief_20260824.md`

## BioBrief 구성

각 뉴스는 다음과 같이 정리됩니다.

-   기사 제목 및 한 줄 요약
-   관련 기업 및 핵심 키워드
-   쉽게 이해하기
-   주요 수치와 의미
-   핵심 의미
-   추가 리서치
-   취업준비생 Insight

7건의 뉴스 분석 후에는 전체 내용을 종합하여 기업의 최근 방향성, 주요
사업 및 기술, 관련 직무와 역량, 자소서·면접에 활용할 수 있는 인사이트를
제공합니다.
